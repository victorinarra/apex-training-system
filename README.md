# APEX Training System

MVP do temporizador de treino intervalado HIIT/Tabata.

## Incluído
- Configuração de preparação, exercício, descanso, séries e ciclos
- Temporizador com estados visuais
- Contagem regressiva e sinais sonoros
- Pausar, reiniciar, avançar e voltar à configuração
- Design responsivo dark premium inspirado na identidade APEX
